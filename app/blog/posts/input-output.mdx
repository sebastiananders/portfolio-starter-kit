Designing for self-acting software. When I started designing 15 years ago we learned about CRUD. The very basic principle of human-computer interactions. Create, read update and delete where the most important and most used commands on the GUI. Now that we entering an era where software acts as an agent, the basic principles do not apply anymore. Or at least they get an update.

## What is changing?

While commanding on a GUI still exists we now act more as a partner, rather than an actor. The relationship between humans and computer change drastically. We now not only type for input. With GenAI input now is a poly channel communication. We now reliably talk to the computer. Our interfaces now see, listen, etc. what we see and create a contextual environment. We as humans are not only responsible for input anymore. That’s the good news.

### HEUREKA

When it comes to output we also have to rethink some paradigms. The computer now talks back to us in an alright manner. It finally works, speaking to a computer. HEUREKA! Also agent avatars are finally getting somewhere. We have reached a state where people cannot distinguish AI generated from real video content anymore. Let that sink in, for a moment. We are not limited to websites, text and images anymore. Communication with machines will be more life like than ever before. 

Seeing input and output improved this much we can go back to our sci-fi fantasies. This is what I want from design. More visionary and more experimental think pieces.

# Started juggling again

If there are two subsequntly following meetings than there is no work done in between. 
I stopped doing deep work in between two meetings. I need to think about the last meeting and the upcoming meeting. 
There is no thinking space for serious work left. So I started to learn juggling again. This has two (actually three) benefits: I can think better, I don't waste my time on social media and I don't sit. Only good things. When the meeting starts I feel energized and already have some thoughts.
